⬅ كل الأقسام قسم الأتمتة (أدمن)
S Sedra Electric

الأتمتة

Automation — «لو حصل كذا → اعمل كذا»If [trigger] → do [action]

للأدمن

ليه القسم ده مهم؟ Why it matters

  • يعمل مهام متكررة تلقائيًا من غير ما حد يفتكر.Runs repetitive tasks automatically.
  • يقلّل الأخطاء والنسيان.Fewer mistakes & misses.
  • أمثلة: عقد صيانة مستحق → اعمل الفاتورة، أو فاتورة متأخرة → نبّهني.e.g. AMC due → create invoice.

إنشاء قاعدة Create a rule

  1. افتح قسم ⚡ الأتمتة (متاح للأدمن).Open Automation (admin).
  2. اضغط «قاعدة جديدة» وسمّيها.Click “New rule”, name it.
  3. اختار الشرط (Trigger) ثم الإجراء (Action).Pick a trigger, then an action.
  4. فعّل القاعدة بـ Enabled واحفظ.Enable & save.
قاعدة «أنشئ فاتورة AMC تلقائيًا» تشتغل مع شرط «عقد الصيانة مستحق» وبجلسة أدمن.

خلاصة Recap

  • الأتمتة = شرط → إجراء.Automation = trigger → action.
  • فعّلها وراجع نتائجها.Enable & monitor.
  • تقفل أي قاعدة بإلغاء التفعيل.Disable anytime.
